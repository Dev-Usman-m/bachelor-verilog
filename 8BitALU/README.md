# 8-Bit Arithmetic Logic Unit (ALU) - Verilog Implementation  

![image](https://github.com/user-attachments/assets/cbe1910e-0c8d-4b30-a4ca-19aa0f74e012)


## Description  
A **Verilog-based 8-bit ALU** designed during my 2016 academic semester. Implements four  bitwise operations:  
- **AND** (`A & B`)  
- **XOR** (`A ^ B`)  
- **XNOR** (`A ~^ B`)  
- **OR** (`A | B`)  

Developed and simulated using **Xilinx ISE Design Suite**.
